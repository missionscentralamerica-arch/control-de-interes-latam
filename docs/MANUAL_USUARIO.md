# Manual de Usuario

## 1. Introducción breve
Este sistema sirve para registrar personas interesadas en la iglesia y hacerles seguimiento desde un panel interno. La idea es que el equipo pueda guardar los datos básicos de quienes visitan un evento, piden información o quieren contacto pastoral.

## 2. Cómo compartir el formulario de registro
1. Abra la página de registro público.
2. Allí verá un enlace para compartir y un botón llamado `Copiar link`.
3. Presione `Copiar link` para llevar la dirección al portapapeles.
4. Pegue ese enlace en un mensaje, en WhatsApp o en redes para que otros puedan registrarse.

### Código QR
1. En la misma página también hay un botón `Ver código QR`.
2. Al hacer clic, verá el código QR que cualquier persona puede escanear con su celular.
3. Puede imprimir ese código o proyectarlo en una pantalla para que la gente lo use fácilmente.

## 3. Cómo entrar al panel
1. Abra la página de login del panel.
2. Ingrese el correo y la contraseña que le entregaron.
3. Presione el botón para iniciar sesión.

### Si olvidó la contraseña
1. Use el enlace `¿Olvidaste tu contraseña?` en la página de login.
2. Siga las instrucciones para recibir un correo con un enlace para cambiar la clave.
3. Si no llega el correo, revise la carpeta de spam o correo no deseado.

## 4. Cómo ver los registros en el panel
1. Una vez que haya iniciado sesión, verá la lista de personas registradas.
2. Cada fila muestra:
   - Nombre completo
   - Correo
   - Código postal
   - Edad
   - Evento donde nos conoció
   - Decisión tomada (Reconciliación / Aceptar a Cristo)
   - Fecha de registro

### Usar filtros de fecha
1. Si desea ver datos de un período específico, seleccione una fecha de inicio y una fecha final.
2. Presione `Aplicar filtros` para ver solo las personas registradas en ese rango.

## 5. Cómo exportar el reporte en PDF
1. En el panel hay un botón llamado `Exportar PDF`.
2. Al hacer clic, se descargará un archivo en formato PDF con los registros actuales.
3. Ese documento incluye la información de cada persona y puede utilizarse para:
   - imprimirlo y revisarlo en reuniones,
   - compartirlo con pastores o líderes,
   - guardar un archivo histórico.

## 6. Cómo cerrar sesión
1. Cuando termine de usar el panel, presione el botón `Cerrar sesión`.
2. Esto es especialmente importante si usa una computadora compartida.
3. Cerrar sesión protege la información y evita que otra persona entre con su cuenta por accidente.

## 7. Preguntas frecuentes
- **¿Qué pasa si alguien se registra dos veces?**
  - En el sistema aparecerán dos registros separados. Si ve duplicados, puede revisarlos con cuidado y hacer un seguimiento adecuado.

- **¿Los datos son privados?**
  - Sí. La información se usa solo para el seguimiento pastoral y no se comparte fuera del equipo.

- **¿Puedo acceder desde el celular?**
  - Sí. El formulario de registro y el panel se pueden usar desde el celular.

- **¿Cómo sé si el registro se guardó bien?**
  - Después de enviar el formulario, debería aparecer un mensaje de confirmación. En el panel también podrá ver el nombre y la fecha de la nueva persona.
